# Quiet List

一个轻量化的 Todo List 原型，帮助用户快速罗列待办事项，并通过百分比直观看到当天完成率。

## 在线预览

本地启动后访问：<http://localhost:4173/>

## 核心功能

- 今日任务：展示今天需要执行的一次性任务和重复任务。
- 长期计划：保存可重复执行的任务模板，并显示下一次执行日期。
- 完成率：根据当天应完成的任务数量实时计算百分比。
- 日期与重复规则：
  - 一次性任务
  - 每天执行
  - 每周指定一个或多个星期几
  - 每隔 N 天执行
- 日期级完成记录：勾选只记录当天的完成状态，长期计划不会消失。
- 日期锁定：未到执行日期的任务不可提前勾选。
- 调色盘：提供 5 个预选色和自定义颜色，并保存主题选择。
- 本地持久化：任务和主题颜色保存在浏览器 `localStorage` 中。

## 快速开始

### 环境要求

- Node.js 18+
- npm

### 安装依赖

```bash
npm install
```

### 启动开发服务

```bash
npm run dev
```

然后打开 <http://localhost:4173/>。

### 构建生产版本

```bash
npm run build
```

### 运行测试

```bash
npm test
```

## 使用说明

1. 在顶部输入框中可以快速添加今日一次性任务。
2. 点击输入框右侧的日历按钮，打开日期和重复设置。
3. 选择执行日期、重复方式和对应参数后保存。
4. 重复任务会在匹配日期自动出现在“今日”。
5. 点击任务左侧勾选框，完成率会立即更新。
6. 点击顶部调色盘图标，可以切换预选色或选择自定义颜色。
